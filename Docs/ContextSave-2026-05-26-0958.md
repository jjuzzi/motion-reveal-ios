## Changes Since Previous Context Save

### Launch / Onboarding Setup

User reported the beginning gyro animation/setup got messed up and pointed at the bottom-right image badge on the cover.

### Waveform Progress Alignment

User reported the big yellow vertical playhead lagged behind song progress. Video frame analysis confirmed the problem:

- Waveform bars were centered in their own intrinsic HStack.
- The yellow playhead used the full parent width.
- At `0:00`, the yellow line appeared far left of the actual waveform bars.

Fix made:

- `WaveformPanel` now computes a shared `waveformTrackRect`.
- Bars, yellow playhead, markers, selected popover position, scrubbing, and long-press marker creation all use the same measured waveform coordinate space.
- This should stop the detached/lagging playhead visual.

Relevant file:

- `MotionReveal/Features/MusicWorkspace/WaveformMarkerViews.swift`

Key symbols:

- `waveformTrackRect(in:)`
- `waveformX(for:in:)`
- `waveformFraction(for:in:)`
- `waveformBarWidth(in:)`

### Waveform Shape / Player Layout

User asked for:

- waveform longer on screen
- waveform less fat
- buttons less spaced out and jumbo
- album cover bigger

Changes made:

- Waveform horizontal inset reduced from `24` to `10`.
- Waveform bars made thinner and shorter.
- Waveform track uses measured full available width.
- Album cover increased:
  - glow frame `276 x 276`
  - cover frame `268 x 268`
  - corner radius increased to `38`
- Media controls reduced:
  - secondary button size `40`
  - primary play/pause size `52`
  - transport button spacing grouped at `42`
  - primary icon size down to `19`
  - secondary icon size down to `14`
  - control strip min height down to `60`

Relevant files:

- `MotionReveal/Features/MusicWorkspace/SongContainerView.swift`
- `MotionReveal/Features/MusicWorkspace/WaveformMarkerViews.swift`

### Dynamic Notch Beam Border

User still reports the beam is uneven. Latest visual note:

- Animated chase color was making still screenshots look uneven because one side appears stronger depending on animation frame.

Latest changes made:

- Full capsule frame adjusted to `126 x 35`, y offset `13.2`.
- Base rim made more consistent:
  - capsule base stroke line width increased to `1.55`
  - opacity `0.94`
- Moving chase color reduced to accent:
  - glow opacity reduced
  - chase stroke opacity reduced
- `DynamicIslandBottomLip` still exists as independent bottom edge.
  - width `116`
  - height `8`
  - line width `1.65`
  - y offset `2.35`
  - corner lift lowered to `rect.height * 0.20`

Relevant file:

- `MotionReveal/Features/MusicWorkspace/IslandSlotViews.swift`

Watch item:

- This still needs fresh iPhone Mirroring screenshot review. If uneven persists, continue tuning `DynamicIslandBottomLip` and base rim before changing full capsule position.
